# 三个已定口径（2026-11-15，作者确认）

这三条不是技术问题，是**语料边界决定**。定了就不在清理时反复讨论。

## 1. 后置块不算结论

致谢（Acknowledgements）、数据可用性（Data availability）、资助声明（Research funding）、作者贡献（Author contributions）、利益冲突声明（Declarations of interest）、缩写表（Abbreviations）、作者简介（Notes on contributor / The authors）、附录（Appendix）——**都不属于结论段正文**。

处置：从标签行起到结尾整段删除，理由码 `tail-block`。
实例：494 篇语料中删了 32 篇的后置块，共约 2000 词。

## 2. 外部出处予以保留

图源（`Source: ...`）、时间戳（`Timestamp: ...`）、视频或资料链接（`Images extracted from: ...`）、脚注残片（`15 Diwersy (2005).`）、参考文献行——**保留**，理由码 `keep`。

但**不允许原样留在句中**：保留项一律移到所在段落的末尾。原因是这些行是 PDF 排版造成的句中插入，留在原处会把句子劈成两半。

实例：494 篇中有 3 篇含这类行（088 的三行图源、302 的一行脚注、483 的一行参考文献），已全部移到段末，句子恢复完整。

## 3. 词数窗口维持 250-600

放宽到 700 可以让落选池中 36 篇「结论本身 600-700 词」的文档入册，但**不这么做**。窗口是语料定义的一部分，不是可以为凑数而调整的参数。

后果：N = 494，不补到 500。要增加 N 只能扩池（重新检索下载），不能在窗口上做文章。
