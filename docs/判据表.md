## 零、三条铁律

1. **只标不删**。任何自动判断都不直接改文本；改文本是独立一步，且必须回读核对。
2. **原件只读**。PDF、上游文本一律不动，产物写新目录。
3. **每处留证**。删了什么、为什么删、删了几个词，全部落 CSV 台账；不写“已清理”这种没有明细的话。

## 一、理由码封闭集

只有这 13 个码，不许自造。每个码给「判据 / 反例 / 处置」。

### 1. `running-head` 页眉
- **判据**（满足任一）：
  - 同一行（数字归一化为 `#` 后）在本文档 **≥2 个页面**出现，且长度 ≤90 字符；
  - 行位于本页**正文区上边界之上**（y0 < 本页第一条长行 y0 − 3），长度 ≤110；
- **特征形态**：`作者名 | 页码`、`页码 | 短标题`、`刊名 卷(期)`、全大写短标题 + 数字。
- **反例（不能删）**：
  - `207 different ways`、`level 102`、`100 times (1.18 pmw)`、`140 character constraint` —— 行首数字是正文的一部分；
  - 结论里出现的表格数值行，虽然在页顶也不算（需与 table 交叉判定）。
- **处置**：整行删除。

### 2. `pagenum` 页码 / 文章号
- **判据**：行匹配 `^\d{1,4}$`；或 `^S\d{1,4}$`（TESOL 的 S 号页）；或 Cambridge 的 `S\d{10}` 样文章号。
- **反例**：全库**没有任何一行纯数字是正文**（已在 v6 冻结阶段用几何规则确认），所以这条几乎不误伤；但若该行在 `table` 区域内，归 `table`。
- **处置**：整行删除。

### 3. `caption` 图题 / 图源
- **判据**：行首匹配 `^(figure|fig\.|table|plate|box|scheme)\s*[0-9ivx]+`；或 `Source:`、`Timestamp:`、`Images extracted from:` 开头。
- **注意**：正文句子里的 `as shown in Table 5, are also harder…` **不是** caption（大小写和行首位置都要满足）。
- **处置**：整行删除（含图源三行连续块时整块删）。

### 4. `table` 表格漏入
- **判据**：行落在 PyMuPDF `find_tables()` 的 bbox 内；或连续 ≥3 行短行（≤45 字符）且无句末标点、含数字/全大写，且位于同一块。
- **注意**：表格里的内容是真的（数据、符号说明），删它是**范围决定**不是清理决定，台账里要标 `note=range-decision`。
- **处置**：整块删除，计入范围说明。

### 5. `watermark` 水印
- **判据**：匹配 `downloaded from / brought to you by / authenticated / download date / pre-proof / postprint / author accepted / manuscript accepted / running head / this content downloaded / © / all rights reserved`（不区分大小写）。
- **特例**：Wiley 的 `MANUSCRIPT` / `ACCEPTED` 竖排水印会拆成两行，两行都删。
- **处置**：整行删除。

### 6. `tail-block` 后置块
- **判据**：行首匹配标签集 \
  `data availability / availability of data / acknowledg(e)?ments? / research funding / funding / author contributions / authors' contributions / declarations? of interest / conflict of interest / competing interests / abbreviations / notes on contributor / about the authors? / the authors / author statement / appendix / supplementary / list of references / references` \
  **且** 前一行以 `. ! ? ” ’ )` 收尾（即上一段已结束）。
- **处置**：从该标签行起到单元格末尾**整块删除**。
- **必须记录**：这是**范围决定**，不是排版垃圾。四个硬证据（本次实测）：
  1. run-in 粗体标签独立成段，不缩进；
  2. 与上一段垂直间距是正文行距的 3.5–4.3 倍；
  3. 4 篇落在**新一页顶端**，前面是页眉；
  4. 之后紧跟 `References` / `Appendix` / `Abbreviations` 大标题（字号 14.9 vs 正文 9.5）。

### 7. `heading-trail` 悬空的下节标题
- **判据**：行很短、无句末标点、像是节标题（如 `Transcription convention`、`List of References`、`Corpus`、`Questions arising`），且位于单元格**最后一行**。
- **处置**：删除该行。

### 8. `footnote-call` 句末粘连的脚注号
- **判据**：行尾形如 `…word.15`、`…robustness.3`——字母 + 标点 + 1–2 位数字，且不是年份（排除 `19xx/20xx`）、不是页码。
- **处置**：**只标数字本身**，不删整行。

### 9. `pipe` 竖线
- **判据**：整行只有 `|`；或行内 `｜` 两侧是空格（当顿号用的排版残留）。
- **处置**：整行只有竖线则删该行；行内竖线**替换为逗号**（不是删）。

### 10. `mojibake` 字形错位
- **判据**：出现可疑 Unicode（`€` 代替 `Ö`、`扖` 代替 `过`、`T€urkiye`）或系统性替换（`ł→ì`、`ʔ→P`）。
- **处置**：**不删**，按对照表替换；对照表必须人工确认，因为可能有两种正确写法（`Orulv` vs `Örulv`）。无对照则登记进 `02_删不掉的问题清单`。

### 11. `dup-word` 词层重复
- **判据**：`influe uence`、`conflic ict`——前词去掉末尾 1 字符 + 后词 = 一个常见词。
- **处置**：合并为一个词。**会让保序子序列失效**，必须在核验里登记为特例。

### 12. `word-split` 断词
- **判据**（两类）：
  - 行尾硬连字符续行 `experi-\nmental`；
  - 同一行内被拆开 `quantif ier`、`f inding`、`def inite`。
- **处置**：合并。**本轮未做**（1675 处，需按词典判），skill 里标为“已知未覆盖”。

### 13. `keep` 明确保留
- **用途**：把“看起来像垃圾但必须留”的登记下来，避免下一个人重复争论。
- **示例**：`Source: …` 图源（外部出处）、脚注残片、参考文献行——本轮 5 处全部保留。

## 四、已知坑（照着避）

1. **不要拿行窗口估词数**。本轮用 `A_lines` 的行窗口估，给出 17 篇可补；改用正文文本实测后只有 8 篇，实际可入册 6 篇。**估算必须在最终文本上做，并用已定稿样本回测**（本轮回测：均值误 1.8、中位 0）。
2. **`split("\n")` 处理 CRLF 会留 `\r`**，导致“同一行”匹配全部失败。用 `split("\r\n")`。
3. **Excel 单行最高 409.5 pt**，超过约 27 行的单元格在表里看不全。必须同时出 CSV 台账。
4. **文件中途写入会留空行**（本轮 471 留了一个），删除后要清空行并复验。
5. **跨页重复判据取 ≥2 还是 ≥3 差别很大**：取 ≥2 命中 491 行，取 ≥3 只剩 128 行。**固定为 ≥2 + 长度 ≤90**，并在 rules 里写死。
6. **不要用“行首数字”判页码**。全库没有纯数字正文行，但 `207 different ways` 这类会被误伤，必须靠几何或跨页重复二次确认。
