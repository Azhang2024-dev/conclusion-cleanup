# v6：全库重跑（模型定位 + 逐字母闸门）

把 697 篇 PDF 的行流原样交给模型，让它自己找结论段的起止、自己去水印页码脚注，
然后用闸门逐字母核对「它交出来的文本，是不是它申报的那几行的原文」。
规则不切文本，只做两件事：**冻结输入**（`A_lines/{sha}.jsonl`，一行一个 JSON）、**验算输出**。

## 为什么要换

v5 之前的做法是规则切分：正则 + 版式几何 + 理由码。规则能切干净页码和页眉，
切不干净「图注后面那句引出语」「Limitations 子节要不要算」「脚注字号与正文一致」这三类，
全库失败率约 12%，且每换一家出版社就要重调阈值。

模型版把判断交出去，把可验证性留下来：闸门看得见改词、看得见漏行，看不见「切歪了」，
所以另加边界对照（与规则引擎比）与形状自查（首字母小写、缺句号、段内出现节标题等）。

## 跑的顺序

| # | 脚本 | 输入 → 输出 |
|---|---|---|
| 1 | `s1_batch.py` | 697 篇 × 2 遍，温度 0 → `{sha}/cplx_t0p0_run{1,2}.json` |
| 2 | `s2_gate.py` | 调 `span-locator/tools/verify_output.py` 逐篇 → `gate.jsonl` |
| 3 | `s4_repeat.py` | run1 vs run2 → `r1_vs_r2.jsonl`（温度 0 到底稳不稳） |
| 4 | `s6_boundary.py` | 模型段 vs 规则段 → `boundary_class` |
| 5 | `s16_overshoot.py` | 越界那 82 篇越到哪儿去了 → `overshoot_kind` |
| 6 | `s12_apply.py` | 复核结论回写（ok / fix / drop） |
| 7 | `s22_selfcheck.py` | 闸门看不见的形状问题 |
| 8 | `s30_dedupe.py` | sha1 / DOI / 标题 / 结论 n-gram Jaccard |
| 9 | `s5_table.py` | 交付工作簿（主表 + 删除明细 + 统计 + 候选池 + 分歧） |
| 10 | `s40/41/42_*.py` | 候选池逐篇亲读 → `fullread.tsv` |

`s11_review_http.py` 是复核包的直连 API 版本：复核员只回 `ok / fix` 与五条判据，
不写正文。密钥走环境变量 `DEEPSEEK_API_KEY`，不进仓库。

## 闸门的三问

`span-locator/tools/verify_output.py`：

1. **行覆盖**：申报区间里每一行正文，要么出现在输出里，要么申报删除。
   家具行（页码、页眉、图注、水印、脚注）允许无声消失。
2. **残差**：存活文本与冻结原文逐字符比对，差异必须落进封闭的允许类
   （`delete_furniture` `delete_footnote_no` `delete_stray_letter`
   `quote_norm` `glyph_fix` `add_dash` `dash_expand`）。**不忽略字母**：改一个词就是 FAIL。
3. **申报核验**：申报删了却还在的行，单独报 `declared_but_kept`。

比对忽略空白、连字符与 Word 校对符——合并断词、去掉多余连字符属于合法清洗。

## 已知未覆盖

- **源缺陷照抄**：`þ` 冒充 `+`、`¼` 冒充破折号、原文拼写错、末行缺句号。
  模型忠实照抄是对的，闸门也不会因此报错。要治只能在冻结层统一替换。
- **口径未定**：结论节内的 Limitations 子节算不算结论。模型自身前后不一致
  （6 篇不收、3 篇收），需要一句话定口径，然后全库按同一口径重跑。
- **体裁混杂**：入册件里约 8–10 篇是综述 / 研究议程 / 座谈会总结的结论，
  作为文本合格，按「实证研究结论」统计时需单列。
