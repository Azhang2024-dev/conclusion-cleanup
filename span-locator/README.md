# span-locator

规则不做判断：模型定位结论段、模型洗正文；规则只冻结原料、只做事后校验。

## 一条命令

```bash
set DEEPSEEK_API_KEY=...          # 直连才需要；不走 dsh 时用得到
python tools/determinism.py --stage <语料根> --n 40 --runs 3 --backend http
```

## 三个文件各自的职责

| 文件 | 做什么 | 不做什么 |
|---|---|---|
| `prompt.md` | 一段固定 prompt：给行流，要起止行 + 洗好的正文 + 丢弃清单 | 不含任何正则、任何理由码表 |
| `tools/verify_output.py` | 闸门：行级覆盖 + 字符级残差，六类修复之外的改动一律 FAIL | 不修改模型输出、不替模型决定 |
| `tools/run_doc.py` | 单篇跑 N 次，落盘每次结果与闸门结论 | 不做判断 |
| `tools/determinism.py` | 抽样测「同一 prompt 两次是否同一答案」 | 不调参、不重试掩盖分歧 |

## 闸门判什么

1. **行级覆盖**：区间内每一行，要么在输出里还在，要么在 `dropped` 里申报过，要么本身是页眉页码题注这类明显杂物。三者都不满足 = 未申报删除。
2. **字符级残差**：把活下来的行拼起来，与模型输出逐字符对齐。允许的差异只有：删脚注号、删孤立字母、补破折号、破折号还原。其余任何字母变化 = 改写。

比较时忽略空白、忽略所有连字符、忽略 Word 校对标记 —— 接合劈词、删多余连字符都属合法清洗，不该被判违规。字母本身不忽略。

## 已验证

用 011be618 做四例离线测试：

| 输入 | 结果 |
|---|---|
| 清洗正确的输出 | PASS |
| 删掉 5 行但不申报 | FAIL，逐行列出 |
| 结尾截断 | FAIL，未申报删除 18 行 |
| 改一个短语（six→several） | FAIL，指出改写位置 |
