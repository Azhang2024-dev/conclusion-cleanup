# 结论段定位与清洗

你读到一篇语言学论文的行流。每行形如 `L1234 | 正文`，行号是原文行流的绝对行号。

## 你要做的事

找出这篇论文的**结论段**，把它的正文洗干净，然后原样交回来。

### 一、边界
- 起点：结论小节标题的下一行。没有标题时，从第一句开始总结本文的那一行起。
- 终点：结论正文最后一行，含最后一句的标点。
- 结论被页眉、页脚、页码、脚注从中间打断时，跨过去继续，别把打断处当终点。

### 二、洗
正文里不该有的，删掉：
- 页眉、页脚、页码、期刊名、作者名行
- 图表说明（Fig. / Figure / Table / Plate / Box / Scheme 开头，或来源、时间戳行）
- 脚注正文与脚注上标号
- 致谢、基金、数据可得性、伦理声明、CRediT 作者贡献、利益冲突、作者简介
- 参考文献条目、附录标题、缩写表
- Word 校对标记（形如 `[37_TD$DIF]`）
- 水印（Downloaded from / Journal Pre-proof / Accepted manuscript 等）

正文里被排印弄坏的，修回来：
- 行末硬连字符把单词劈开 → 接合
- 破折号被抽成字母 `d` / `e` / `þ`（`participantsdboth`）→ 还原成 `—`
- 词间空格丢失（`wepresented`）→ 补回
- 词内多出孤立字母（`genre-specific c knowledge`）→ 删掉
- 句末脚注号（`standing.22`）→ 删号保句

**除了上面这些，一个字都不许改。** 不许改写、不许缩写、不许润色、不许补全你不确定的内容。

### 三、输出

只输出一个 JSON，不要解释、不要 markdown 代码块：

```json
{
  "start_line": 1662,
  "end_line": 1735,
  "text": "清洗后的结论段全文，段与段之间用 \n\n 分隔",
  "dropped": [{"line": 1659, "why": "running-head"}],
  "confidence": "high"
}
```

- `start_line` / `end_line`：原文行号，整数
- `dropped`：区间内被你扔掉的每一行，`why` 不超过 4 个词
- `text`：只能是 `start_line` 到 `end_line` 这些行清洗后的结果，句子顺序不许变
